# GlobalStrain

!syntax description /ScalarKernels/GlobalStrain

## Description

`GlobalStrain` solves the ODE equation setting the integral of the stress generated by applied load or volume change unrelated to deformation to zero. It stores the strain components into scalar variables of different order. Strain components calculated from this scalar kernel contribute towards the global strain. Combined with periodic displacements, this helps maintain full strain periodicity; explicitly active directions also support nonperiodic plane-remains-plane applications.

It requires an input of the `UserObject` that calculates the integral value and corresponding jacobians.

Please refer to [GlobalStrainUserObject](/GlobalStrainUserObject.md) for information about the residual and jacobian calculation.
